# 4. Контрастивное обучение и metric learning

### Термины

| Термин | Определение |
|--------|-------------|
| Контрастивное обучение | Парадигма обучения представлений, в которой модель оптимизируется на задаче различения семантически близких (positive) и далёких (negative) пар объектов без использования абсолютных классовых меток |
| Metric learning | Задача обучения отображения данных в метрическое пространство, в котором выбранная метрика отражает семантическую близость объектов |
| Positive pair | Пара объектов, для которой целевое расстояние в embedding-пространстве минимизируется |
| Negative pair | Пара объектов, для которой целевое расстояние в embedding-пространстве максимизируется |
| Hard negative | Negative-пример с высокой оценкой близости к anchor по текущей модели — наиболее информативный для градиентного обновления |
| Функция потерь (loss function) | Скалярный функционал, минимизация которого соответствует улучшению качества модели |
| NT-Xent loss | Normalized Temperature-scaled Cross-Entropy loss — контрастивная функция потерь с температурным масштабированием |
| Anchor loss | Регуляризующая функция потерь, обеспечивающая компактификацию представлений санкционных адресов (anchors) и их отделение от non-anchors |
| Silhouette score | Метрика качества кластеризации, квантифицирующая согласованность объекта с собственным кластером относительно ближайшего чужого |
| Recall@K | Доля истинных соседей объекта, попадающих в множество $K$ ближайших соседей в embedding-пространстве |
| KS-тест | Критерий Колмогорова — Смирнова для проверки гипотезы об идентичности двух распределений |
| PR-AUC | Площадь под Precision-Recall кривой |
| ECE | Expected Calibration Error |
| Brier score | Среднеквадратичная ошибка между предсказанной вероятностью и бинарным исходом |

## 4.1. Постановка задачи

On-chain данные допускают представление в виде графа, а GNN отображают кошелёк $x \in \mathcal{X}$ в embedding $z = f_\theta(x) \in \mathbb{R}^d$, кодирующий структурно-поведенческую роль. Открытым остаётся спецификация отображения $f_\theta$: как оптимизировать параметры $\theta$, чтобы геометрия $\mathbb{R}^d$ отражала поведенческую эквивалентность.

Классическая постановка supervised learning предполагает размеченную выборку $\{(x_i, y_i)\}_{i=1}^N$, $y_i \in \{0,1\}$. В контексте Spillety она неприменима: полная ручная разметка $10^6$–$10^7$ адресов экономически нереализуема; распределение illicit-паттернов нестационарно (concept drift).

Контрастивное обучение устраняет зависимость от абсолютных меток, заменяя их относительными сигналами: модель оптимизируется на сохранении отношения «$a$ и $b$ семантически ближе, чем $a$ и $c$».

## 4.2. Контрастивное обучение

### 4.2.1. Формирование пар

Контрастивное обучение оперирует тройками $(a, p, n)$, где $a$ — anchor, $p$ — positive (семантически близкий к $a$), $n$ — negative (семантически далёкий от $a$). Цель:

$$
\text{sim}(f_\theta(a), f_\theta(p)) > \text{sim}(f_\theta(a), f_\theta(n))
$$

для меры близости $\text{sim}(\cdot,\cdot)$, как правило — косинусной.

Для каждого элемента батча формируется одна positive пара и $2N-2$ negative пар (остальные элементы батча в симметризованной постановке).

### 4.2.2. NT-Xent Loss

NT-Xent loss для пары $(i, j)$, где $i$ — якорь, $j$ — positive:

$$
\ell_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j) / \tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k) / \tau)}
$$

где:
- $z_i = f_\theta(x_i)$, $z_j = f_\theta(x_j)$ — $\ell_2$-нормализованные embeddings, $\|z\|_2 = 1$;
- $\text{sim}(u, v) = u^\top v$ для нормализованных векторов;
- $\tau > 0$ — температурный параметр;
- $N$ — размер исходного батча до аугментации (эффективный размер $2N$).

Числитель максимизирует близость positive-пары, знаменатель минимизирует близость ко всем negative-примерам. Минимизация $\ell_{i,j}$ эквивалентна максимизации нижней оценки взаимной информации $I(z_i; z_j)$.

**Интерпретация $\tau$.** При $\tau \to 0$ распределение концентрируется на ближайшем negative (акцент на hard negatives); при $\tau \to \infty$ — стремится к равномерному. Эмпирически рассматриваются $\tau \in \{0.05, 0.1, 0.2\}$; выбор на валидационной выборке.

![ntxent_training_curve](./files/4-2-2_ntxent_training_curve.png)

*Динамика NT-Xent loss: монотонное убывание на обучающей выборке и стабилизация на валидационной. Точка минимума валидационного loss определяет оптимальное число эпох по критерию early stopping.*

> **Определение.** Эпоха обучения — один полный проход оптимизационного алгоритма по всей обучающей выборке.

## 4.3. Формирование пар в контексте Spillety

### 4.3.1. Positive пары

| Тип | Критерий формирования | Обоснование |
|-----|------------------------|-------------|
| Co-spending | Два адреса Bitcoin, фигурирующие как входы одной транзакции | CIOH: совместное расходование входов с высокой вероятностью указывает на единого владельца |
| Temporal proximity | Транзакции, разделённые интервалом $\Delta t < \epsilon$ | Скоординированная активность одного актора |
| News co-mention | Совместное упоминание адресов/сущностей в одном новостном документе | Контекстуальная семантическая связь |
| Same high-confidence cluster | Адреса, принадлежащие одному кластеру entity resolution с confidence выше порога $\tau_c$ | Результат процедуры разрешения сущностей (см. раздел 5) |

### 4.3.2. Negative пары

| Тип | Критерий формирования | Обоснование |
|-----|------------------------|-------------|
| Random wallets (degree-corrected) | Случайная выборка пар адресов с коррекцией по степени узла | Устранение смещения в сторону высокостепенных узлов |
| Hard negatives | Адреса из одного временного окна, но принадлежащие различным кластерам | Максимальная информативность |

**Degree-corrected sampling.** Равномерная выборка negative-примеров смещена в сторону узлов с высокой степенью. Вероятность выборки узла $v$ задаётся обратно пропорционально его степени: $p(v) \propto 1 / \deg(v)^\alpha$, $\alpha \in [0.5, 1]$ — параметр, подбираемый эмпирически.

**Стратегия hard negatives.** Введение hard negatives на ранних стадиях обучения дестабилизирует оптимизацию. Рекомендуемая стратегия — curriculum: hard negatives вводятся на средних и поздних стадиях, когда базовая структура embedding-пространства уже сформирована.

## 4.4. Anchor Loss: использование санкционных списков

### 4.4.1. Принцип

Санкционные перечни OFAC SDN, EU Consolidated Financial Sanctions, UN Security Council Consolidated List и UK OFSI содержат адреса с верифицированной illicit-аффилиацией. Их непосредственное использование как меток для supervised learning возвращает к ограничениям этого подхода. Взамен множество санкционных адресов $\mathcal{A}$ трактуется как **система координат** в embedding-пространстве: модель оптимизируется так, чтобы отображения элементов $\mathcal{A}$ формировали компактную область, отделимую от non-anchors $\mathcal{N}$.

### 4.4.2. Формализация

Пусть $\mathcal{A}$ — множество anchors, $\mathcal{N}$ — множество non-anchors. Anchor loss — сумма двух hinge-компонент:

$$
\mathcal{L}_{\text{anchor}} = \sum_{a_i, a_j \in \mathcal{A}} \max(0, \|z_{a_i} - z_{a_j}\|_2 - m_{\text{pull}}) + \sum_{a \in \mathcal{A}, n \in \mathcal{N}} \max(0, m_{\text{push}} - \|z_a - z_n\|_2)
$$

- Первое слагаемое — притяжение anchors: расстояние между любыми двумя anchors не превышает $m_{\text{pull}}$.
- Второе — отталкивание: расстояние между anchor и non-anchor не менее $m_{\text{push}}$.

Итоговая функция потерь:

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{NT-Xent}} + \lambda \cdot \mathcal{L}_{\text{anchor}}
$$

где $\lambda \geq 0$ — коэффициент баланса. Частные случаи: $\lambda = 0$ — чистый NT-Xent; $\lambda > 0$ — комбинированная оптимизация. Выбор между $\mathcal{L}_{\text{NT-Xent}}$ и $\mathcal{L}_{\text{NT-Xent}} + \lambda \mathcal{L}_{\text{anchor}}$, а также калибровка $\lambda$, осуществляются экспериментально по метрикам раздела 4.6.

### 4.4.3. Гетерогенность anchors и weighted margin

Степень согласованности санкционных перечней квантифицируется коэффициентом Жаккара:

$$
J(L_1, L_2) = \frac{|L_1 \cap L_2|}{|L_1 \cup L_2|} \in [0,1]
$$

Взвешенный margin притяжения:

$$
m_{\text{pull}}^{(L_1, L_2)} = m_0 \cdot (1 - J(L_1, L_2))
$$

При $J \to 1$ требуется максимальная близость anchors из согласованных перечней; при $J \to 0$ допускается максимальное удаление. Калибровка $m_0$ — в ходе гиперпараметрического поиска.

## 4.5. Metric learning

### 4.5.1. Формулировка

Metric learning — задача обучения отображения $f: \mathcal{X} \to \mathbb{R}^d$, при котором стандартная метрика в образе отражает семантическую близость в прообразе:

$$
\min_f \sum_{(i,j) \in \mathcal{P}} \|f(x_i) - f(x_j)\|_2^2 - \gamma \sum_{(i,j) \in \mathcal{N}} \|f(x_i) - f(x_j)\|_2^2
$$

где $\mathcal{P}$, $\mathcal{N}$ — множества positive и negative пар, $\gamma$ — коэффициент баланса. В контрастивной формулировке задача решается неявно через минимизацию NT-Xent loss.

### 4.5.2. Связь с InfoNCE

NT-Xent loss — частный случай InfoNCE (Noise-Contrastive Estimation). InfoNCE максимизирует нижнюю оценку взаимной информации:

$$
I(z_i; z_j) \geq \log N - \mathcal{L}_{\text{InfoNCE}}
$$

Увеличение числа negatives повышает точность оценки взаимной информации, что обосновывает эффективность контрастивного обучения при больших размерах батча.

## 4.6. Оценка качества embeddings

Оценка: silhouette, recall@K, KS, PR-AUC, ECE, Brier. Набор обеспечивает комплексную характеристику: геометрическую разделимость кластеров, точность retrieval, устойчивость к темпоральному сдвигу, дискриминативную способность и калибровку.

Протокол: фиксация hold-out выборки (подмножество Elliptic++ с известными метками) и вычисление всех метрик на фиксированном разбиении train/validation/test с темпоральным разрезом.

### 4.6.1. Silhouette score

Для объекта $i$, принадлежащего кластеру $C(i)$:

$$
s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))} \in [-1, 1]
$$

где:
- $a(i) = \frac{1}{|C(i)|-1}\sum_{j \in C(i), j \neq i} d(i,j)$ — среднее внутрикластерное расстояние;
- $b(i) = \min_{C' \neq C(i)} \frac{1}{|C'|}\sum_{j \in C'} d(i,j)$ — среднее расстояние до ближайшего чужого кластера;
- $d(\cdot,\cdot)$ — евклидово расстояние.

Интерпретация: $s(i) \approx 1$ — объект существенно ближе к собственному кластеру; $s(i) \approx 0$ — на границе; $s(i) < 0$ — вероятно, отнесён к неверному кластеру. Агрегированная метрика — среднее $\bar{s} = \frac{1}{N}\sum_i s(i)$.

![silhouette_analysis](./files/4-6-1_silhouette_analysis.png)

*Распределение silhouette-коэффициентов по кластерам. Широкие столбцы с высокими значениями соответствуют хорошо отделённым кластерам. Красная вертикальная линия — среднее $\bar{s}$.*

### 4.6.2. Recall@K

**Процедура вычисления:**
1. Для каждого запроса $q$ из тестового множества определяется $R_K(q)$ — $K$ ближайших соседей по косинусной близости.
2. $G(q)$ — множество ground-truth соседей $q$ (anchors, семантически связанных по разметке Elliptic++ или по принадлежности к одному entity-кластеру).
3. $\text{Recall@K}(q) = |R_K(q) \cap G(q)| / |G(q)|$.
4. Агрегированная метрика: $\text{Recall@K} = \frac{1}{|Q|}\sum_{q \in Q}\text{Recall@K}(q)$.

Типичные значения $K \in \{10, 50, 100\}$.

### 4.6.3. Стабильность при темпоральном сдвиге (KS-тест)

Требование: при отсутствии изменений в поведении кошелька его представление не должно претерпевать статистически значимых сдвигов при инкрементальном обновлении графа.

Для двух временных срезов $t_1$ и $t_2$ формируются выборки проекций embeddings. Применяется двухвыборочный критерий Колмогорова — Смирнова:

$$
D_{n,m} = \sup_x |F_{1,n}(x) - F_{2,m}(x)|
$$

Нулевая гипотеза $H_0: F_1 = F_2$ отвергается при $p < 0.05$.

Для каждого временного среза вычисляется статистика $D_{n,m}$ и $p$-значение. Отсутствие значимых различий ($p \geq 0.05$) — темпоральная стабильность; $p < 0.05$ — сигнал к retraining.

Визуализация embedding-пространства — через t-SNE или UMAP.

![embeddings in space](./files/4-7_embedding_tsne.png)

*Проекция 128-мерного embedding-пространства в $\mathbb{R}^2$ методом t-SNE. При корректном обучении anchors различных типов (OFAC, mixer, exchange) формируют компактные, взаимно отделённые кластеры.*

### 4.6.4. Дискриминативные и калибровочные метрики

По расстоянию $d(q, a) = \|z_q - z_a\|_2$ предсказывается метка $y \in \{0,1\}$.

**PR-AUC:**

$$
\text{PR-AUC} = \int_0^1 \text{Precision}(R)\, dR
$$

Устойчива к дисбалансу классов и приоритетна над ROC-AUC в условиях редкости positive-пар.

**ECE:**

$$
\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \bigl|\text{acc}(B_m) - \text{conf}(B_m)\bigr|
$$

**Brier score:**

$$
\text{Brier} = \frac{1}{N}\sum_{i=1}^{N} (\hat{p}_i - y_i)^2 \in [0,1]
$$

Минимальное значение — идеальная калибровка и дискриминация.

## 4.7. Выбор конфигурации

### 4.7.1. Пространство поиска

| Фактор | Рассматриваемые варианты | Примечания |
|--------|--------------------------|------------|
| Функция потерь | (a) чистый NT-Xent; (b) NT-Xent + anchor loss | Баланс $\lambda \in \{0, 0.1, 0.5, 1.0, 2.0\}$ |
| Margin $m_0$ (anchor loss) | $m_0 \in \{0.5, 1.0, 2.0, 4.0\}$ | Взвешивается через $m_{\text{pull}}^{(L_1,L_2)} = m_0(1-J)$ |
| Размерность embedding | $d \in \{64, 128, 256\}$ | Компромисс выразительность / вычислительная стоимость |
| Температура $\tau$ | $\tau \in \{0.05, 0.1, 0.2\}$ | Дополнительно $\tau=0.5$ как гладкий режим |
| Размер батча | $B \in \{256, 1024, 4096\}$ | Эффективный размер $2B$ после аугментации |
| Аугментации графа | (i) feature masking; (ii) edge dropping; (iii) node feature perturbation; (iv) комбинации | Уровень $p \in \{0.1, 0.2, 0.3\}$ |

### 4.7.2. Протокол сравнения

Каждая конфигурация ранжируется по совокупности метрик на валидационной выборке с темпоральным разрезом.

| Тест | Метрики | Критерий |
|------|---------|----------|
| Геометрическая разделимость | silhouette ($\bar{s}$) | Максимизация $\bar{s}$ на hold-out кластерах Elliptic++ |
| Качество retrieval | Recall@K, $K \in \{10,50,100\}$ | Максимизация на anchor retrieval |
| Дискриминация по расстоянию | PR-AUC | Максимизация для предсказания связи по $\|z_i-z_j\|_2$ |
| Калибровка | ECE, Brier | Минимизация |
| Темпоральная стабильность | KS-тест ($D_{n,m}$, $p$-значение) | Отсутствие значимых сдвигов ($p \geq 0.05$) |
| Сходимость | Динамика $\mathcal{L}_{\text{NT-Xent}}$ на validation | Ранняя остановка по минимуму validation loss |

**Процедура выбора:**
1. Отсечение конфигураций с деградацией PR-AUC $>2$ п.п. относительно лучшего значения.
2. Среди оставшихся — минимизация ECE/Brier.
3. При статистической неразличимости по PR-AUC/ECE (тест ДеЛонга для PR-AUC, bootstrap для ECE) — предпочтение конфигурации с более высоким silhouette и Recall@K.
4. Проверка KS-стабильности: конфигурации с $p < 0.01$ штрафуются.
5. При равенстве метрик — предпочтение меньшей размерности $d$ и меньшему батчу $B$.

**Ожидаемые эффекты:**
- Добавление anchor loss ($\lambda > 0$) повышает silhouette для anchor-кластеров и PR-AUC anchor retrieval ценой возможного снижения общей разделимости non-anchor кластеров.
- Увеличение $d$ с 64 до 128 повышает PR-AUC и Recall@K; переход к 256 даёт убывающую отдачу при росте стоимости хранения и CPU-поиска.
- Малые $\tau = 0.05$ усиливают чувствительность к hard negatives (рост Recall@K), но повышают ECE и риск нестабильности; $\tau = 0.2$ обеспечивает более гладкую калибровку.
- Большие батчи ($B=4096$) улучшают оценку взаимной информации (рост PR-AUC), но требуют пропорционального увеличения ресурсов; $B=1024$ часто является парето-оптимальным.

## 4.8. Практические аспекты обучения

### 4.8.1. Размер батча

NT-Xent loss требует достаточного числа negative-примеров. Рассматриваются $B \in \{256, 1024, 4096\}$. Увеличение $B$ монотонно улучшает PR-AUC и Recall@K до насыщения; вычислительная сложность растёт как $O(B^2 d)$ на шаг. Обучение допускается на GPU, inference — CPU-совместимый.

### 4.8.2. Аугментации

Аугментация — стохастическое преобразование графа, сохраняющее семантику узла.

- **Feature masking:** обнуление каждой компоненты признака узла с вероятностью $p$.
- **Edge dropping:** удаление каждого ребра с вероятностью $p$.
- **Node feature perturbation:** аддитивный гауссов шум $\mathcal{N}(0, \sigma^2)$.

Уровень $p \in \{0.1, 0.2, 0.3\}$ и комбинация операторов — предмет поиска. Чрезмерно агрессивные аугментации ($p > 0.3$) разрушают семантику и снижают PR-AUC; чрезмерно слабые ($p < 0.1$) не обеспечивают достаточной вариативности.

### 4.8.3. Температурный параметр $\tau$

Кандидаты $\tau \in \{0.05, 0.1, 0.2\}$ сравниваются по PR-AUC/ECE/Brier/silhouette/Recall@K. Малые значения повышают дискриминативную способность на hard negatives, но ухудшают калибровку (рост ECE); большие стабилизируют обучение ценой снижения Recall@K. Типичный оптимум в литературе — $\tau = 0.07$–$0.1$.

---

## 4.9. Ограничения

1. **Зависимость от качества аугментаций.** Нарушение семантической инвариантности порождает зашумлённые positive-пары, деградируя все метрики.

2. **Проблема ложных negatives.** В on-chain графе значительная доля negative-пар может быть скрыто связана (непубличные каналы, оффчейн-координация). Это вносит систематический шум, занижающий PR-AUC и Recall@K; mitigation — degree-corrected sampling и фильтрация hard negatives по entity-кластерам.

3. **Темпоральный дрейф.** Embeddings, оптимизированные на исторических срезах, деградируют при появлении новых паттернов. Детекция — KS-тест; mitigation — периодический retraining с валидацией по PR-AUC/ECE на скользящем окне.

4. **Отсутствие абсолютной интерпретации расстояния.** Близость в embedding-пространстве — относительная мера. Утверждение «близко к OFAC» не эквивалентно «является OFAC-сущностью» и требует downstream-процедур каузальной фильтрации и GBDT-скоринга.
