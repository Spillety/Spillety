# Контекст и мотивация

Spillety — попытка сделать KYT-движок, который:

- не нуждается в ручной разметке 
- работает на CPU
- адаптируется к новым санкциям без retraining
- выдерживает Daubert (или аналогичные проверки) при необходимости 

Данный раздел (`docs/theory/`) описывает необходимую теорию для понимания всей работы проекта: используемые подходы, технологии, роль и причину их выбора.
