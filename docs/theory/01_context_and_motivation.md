# Контекст и мотивация

Spillety — KYT-движок со следующими свойствами:

- Не требует ручной разметки.
- Работает на CPU.
- Адаптируется к новым санкциям без переобучения.
- Выдерживает проверку Daubert при необходимости.

Раздел `docs/theory/` описывает подходы, технологии и обоснование их выбора.
