# Spillety

Spill the tea about your transactions.

Spillety - студенческий Know Your Transaction движок. Он основан на открытых данных и не требует больших вычислительных мощностей для работы. В нём сконцентрированы самые сильные решения, применяемые в Chainalysis, Elliptic и TRM Labs, классический подход был скорректирован академической теорией и идеями из разделов математики и алгоритмики. 

Теория для погружения в проект [здесь](./docs/theory/).
