# 4. Контрастивное обучение и metric learning

### Термины

| Термин | Определение |
|--------|-------------|
| Контрастивное обучение | Парадигма обучения представлений, в которой модель оптимизируется на задаче различения семантически близких (positive) и далёких (negative) пар объектов без использования абсолютных классовых меток |
| Metric learning | Задача обучения отображения данных в метрическое пространство, в котором выбранная метрика (евклидова, косинусная) отражает семантическую близость объектов |
| Positive pair | Пара объектов, для которой целевое расстояние в embedding-пространстве минимизируется |
| Negative pair | Пара объектов, для которой целевое расстояние в embedding-пространстве максимизируется |
| Hard negative | Negative-пример с высокой оценкой близости к anchor по текущей модели, то есть наиболее информативный для градиентного обновления |
| Функция потерь (loss function) | Скалярный функционал, минимизация которого соответствует улучшению качества модели; синонимы: функционал качества, loss |
| NT-Xent loss | Normalized Temperature-scaled Cross-Entropy loss — контрастивная функция потерь с температурным масштабированием |
| Anchor loss | Регуляризующая функция потерь, обеспечивающая компактификацию представлений санкционных адресов (anchors) и их отделение от non-anchors |
| Silhouette score | Метрика качества кластеризации, квантифицирующая согласованность объекта с собственным кластером относительно ближайшего чужого кластера |
| Recall@K | Метрика качества ранжирования: доля истинных соседей объекта, попадающих в множество $K$ ближайших соседей в embedding-пространстве |
| KS-тест | Критерий Колмогорова — Смирнова для проверки гипотезы об идентичности двух распределений |
| PR-AUC | Площадь под Precision-Recall кривой, интегральная мера качества бинарной классификации при дисбалансе классов |
| ECE | Expected Calibration Error — взвешенное среднее расхождение между предсказанной уверенностью и эмпирической точностью |
| Brier score | Среднеквадратичная ошибка между предсказанной вероятностью и бинарным исходом |

## 4.1. Постановка задачи

В предшествующих разделах установлено, что on-chain данные допускают естественное представление в виде графа, а графовые нейронные сети позволяют отобразить кошелёк $x \in \mathcal{X}$ в векторное представление (embedding) $z = f_\theta(x) \in \mathbb{R}^d$, кодирующее его структурно-поведенческую роль. Открытым остаётся вопрос спецификации отображения $f_\theta$: каким образом следует оптимизировать параметры $\theta$ так, чтобы геометрия пространства $\mathbb{R}^d$ отражала поведенческую эквивалентность кошельков.

Классическая постановка обучения с учителем (supervised learning) предполагает наличие размеченной выборки $\{(x_i, y_i)\}_{i=1}^N$, где $y_i \in \{0,1\}$ — метка illicit/licit. В контексте Spillety данная постановка неприменима по двум причинам. Во-первых, полная ручная разметка множества адресов порядка $10^6$–$10^7$ экономически нереализуема. Во-вторых, распределение illicit-паттернов нестационарно: модель, оптимизированная на исторической разметке, подвержена деградации при концептуальном дрейфе (concept drift).

Контрастивное обучение устраняет зависимость от абсолютных меток, заменяя их относительными сигналами: модель оптимизируется не на предсказании метки отдельного объекта, а на сохранении отношения «объекты $a$ и $b$ семантически ближе, чем $a$ и $c$».

## 4.2. Контрастивное обучение: принцип работы

### 4.2.1. Формирование пар

Формально контрастивное обучение оперирует тройками $(a, p, n)$, где $a$ — anchor (якорный объект), $p$ — positive (семантически близкий к $a$), $n$ — negative (семантически далёкий от $a$). Цель отображения $f_\theta$ — обеспечить выполнение неравенства:

$$
\text{sim}(f_\theta(a), f_\theta(p)) > \text{sim}(f_\theta(a), f_\theta(n))
$$

для заданной меры близости $\text{sim}(\cdot,\cdot)$, как правило — косинусной.

Для каждого элемента батча формируется одна positive пара и $2N-2$ negative пар (остальные элементы батча в симметризованной постановке), что позволяет свести задачу к классификации positive среди negatives.

### 4.2.2. NT-Xent Loss

Формальная спецификация NT-Xent loss для пары $(i, j)$, где $i$ — якорь, $j$ — positive, имеет вид:

$$
\ell_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j) / \tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k) / \tau)}
$$

где:
- $z_i = f_\theta(x_i)$, $z_j = f_\theta(x_j)$ — $\ell_2$-нормализованные embeddings, $\|z\|_2 = 1$;
- $\text{sim}(u, v) = u^\top v / (\|u\|\|v\|) = u^\top v$ для нормализованных векторов — косинусная близость;
- $\tau > 0$ — температурный параметр;
- $N$ — размер исходного батча до аугментации (эффективный размер $2N$).

Числитель максимизирует близость positive-пары, знаменатель минимизирует близость ко всем negative-примерам батча. Минимизация $\ell_{i,j}$ эквивалентна максимизации нижней оценки взаимной информации $I(z_i; z_j)$ (см. раздел 4.5.2).

**Интерпретация температурного параметра $\tau$.** Параметр $\tau$ регулирует энтропию softmax-распределения в знаменателе. При $\tau \to 0$ распределение концентрируется на ближайшем negative (акцент на hard negatives); при $\tau \to \infty$ распределение стремится к равномерному. Эмпирически рассматриваются значения $\tau \in \{0.05, 0.1, 0.2\}$; выбор осуществляется на валидационной выборке по критериям, описанным в разделе 4.6 (см. также раздел 4.7).

![ntxent_training_curve](./files/4-2-2_ntxent_training_curve.png)

*Динамика NT-Xent loss: монотонное убывание на обучающей выборке и стабилизация на валидационной. Точка минимума валидационного loss определяет оптимальное число эпох по критерию early stopping.*

> **Определение.** Эпоха обучения — один полный проход оптимизационного алгоритма по всей обучающей выборке.

## 4.3. Формирование пар в контексте Spillety

Семантика positive/negative определяется доменной спецификой on-chain данных.

### 4.3.1. Positive пары

| Тип | Критерий формирования | Теоретическое обоснование |
|-----|------------------------|---------------------------|
| Co-spending | Два адреса Bitcoin, фигурирующие как входы одной транзакции | CIOH (Common Input Ownership Heuristic): совместное расходование входов с высокой вероятностью указывает на единого владельца |
| Temporal proximity | Транзакции, разделённые интервалом $\Delta t < \epsilon$ (узкое временное окно) | Скоординированная активность одного актора |
| News co-mention | Совместное упоминание адресов/сущностей в одном новостном документе | Контекстуальная семантическая связь |
| Same high-confidence cluster | Адреса, принадлежащие одному кластеру entity resolution с confidence выше порога $\tau_c$ | Результат процедуры разрешения сущностей (см. раздел 5) |

### 4.3.2. Negative пары

| Тип | Критерий формирования | Теоретическое обоснование |
|-----|------------------------|---------------------------|
| Random wallets (degree-corrected) | Случайная выборка пар адресов с коррекцией по степени узла | Устранение смещения в сторону высокостепенных узлов (биржи, популярные контракты) |
| Hard negatives | Адреса из одного временного окна, но принадлежащие различным кластерам | Максимальная информативность при наличии дискриминативной способности модели |

**Degree-corrected sampling.** Равномерная выборка negative-примеров смещена в сторону узлов с высокой степенью центральности. Для обеспечения репрезентативности вероятность выборки узла $v$ задаётся обратно пропорционально его степени: $p(v) \propto 1 / \deg(v)^\alpha$, где $\alpha \in [0.5, 1]$ — параметр коррекции, подбираемый эмпирически.

**Стратегия введения hard negatives.** Эмпирические исследования демонстрируют, что введение hard negatives на ранних стадиях обучения дестабилизирует оптимизацию, поскольку модель не обладает достаточной дискриминативной способностью для их корректной обработки. Рекомендуемая стратегия — curriculum: hard negatives вводятся на средних и поздних стадиях обучения, когда базовая структура embedding-пространства уже сформирована.

## 4.4. Anchor Loss: использование санкционных списков

### 4.4.1. Принцип

Санкционные перечни OFAC SDN, EU Consolidated Financial Sanctions, UN Security Council Consolidated List и UK OFSI содержат адреса с верифицированной illicit-аффилиацией. Непосредственное использование данных перечней в качестве меток для обучения с учителем возвращает к ограничениям supervised-подхода. Взамен предлагается трактовать множество санкционных адресов $\mathcal{A}$ как **систему координат** в embedding-пространстве: модель оптимизируется таким образом, чтобы отображения элементов $\mathcal{A}$ формировали компактную область, отделимую от области non-anchors $\mathcal{N}$.

### 4.4.2. Формализация

Пусть $\mathcal{A}$ — множество anchors, $\mathcal{N}$ — множество non-anchors. Anchor loss определяется как сумма двух hinge-компонент:

$$
\mathcal{L}_{\text{anchor}} = \sum_{a_i, a_j \in \mathcal{A}} \max(0, \|z_{a_i} - z_{a_j}\|_2 - m_{\text{pull}}) + \sum_{a \in \mathcal{A}, n \in \mathcal{N}} \max(0, m_{\text{push}} - \|z_a - z_n\|_2)
$$

где:
- первое слагаемое реализует притяжение anchors: евклидово расстояние между любыми двумя anchors не должно превышать порог $m_{\text{pull}}$;
- второе слагаемое реализует отталкивание: расстояние между anchor и non-anchor должно быть не менее $m_{\text{push}}$;
- $\|\cdot\|_2$ — евклидова норма в $\mathbb{R}^d$.

Итоговая функция потерь контрастивного обучения с учётом anchor-регуляризации:

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{NT-Xent}} + \lambda \cdot \mathcal{L}_{\text{anchor}}
$$

где $\lambda \geq 0$ — коэффициент баланса. Частные случаи: $\lambda = 0$ соответствует чистому NT-Xent; $\lambda > 0$ — комбинированной оптимизации. Выбор между вариантами $\mathcal{L}_{\text{NT-Xent}}$ и $\mathcal{L}_{\text{NT-Xent}} + \lambda \mathcal{L}_{\text{anchor}}$, а также калибровка $\lambda$, осуществляются экспериментально по метрикам раздела 4.6 (см. раздел 4.7).

### 4.4.3. Гетерогенность anchors и weighted margin

Санкционные перечни гетерогенны по охвату и критериям включения. Степень их согласованности квантифицируется коэффициентом Жаккара. Для пары перечней $(L_1, L_2)$:

$$
J(L_1, L_2) = \frac{|L_1 \cap L_2|}{|L_1 \cup L_2|} \in [0,1]
$$

Высокое значение $J$ свидетельствует о согласованности перечней (близкие типы illicit-активности), низкое — о дивергенции. Для учёта гетерогенности вводится взвешенный margin притяжения:

$$
m_{\text{pull}}^{(L_1, L_2)} = m_0 \cdot (1 - J(L_1, L_2))
$$

где $m_0$ — базовый margin. Предельные случаи: при $J \to 1$ величина $m_{\text{pull}}^{(L_1, L_2)} \to 0$ (требование максимальной близости anchors из согласованных перечней); при $J \to 0$ величина $m_{\text{pull}}^{(L_1, L_2)} \to m_0$ (допускается максимальное удаление). Калибровка $m_0$ производится в ходе гиперпараметрического поиска (см. раздел 4.7).

## 4.5. Metric learning: обучение пространства

### 4.5.1. Формулировка metric learning

Metric learning определяется как задача обучения отображения $f: \mathcal{X} \to \mathbb{R}^d$, при котором стандартная метрика в образе (евклидова или косинусная) отражает семантическую близость в прообразе. В терминах оптимизации:

$$
\min_f \sum_{(i,j) \in \mathcal{P}} \|f(x_i) - f(x_j)\|_2^2 - \gamma \sum_{(i,j) \in \mathcal{N}} \|f(x_i) - f(x_j)\|_2^2
$$

где $\mathcal{P}$, $\mathcal{N}$ — множества positive и negative пар соответственно, $\gamma$ — коэффициент баланса. В контрастивной формулировке данная задача решается неявно через минимизацию NT-Xent loss.

### 4.5.2. Связь с InfoNCE

NT-Xent loss является частным случаем InfoNCE (Noise-Contrastive Estimation). InfoNCE максимизирует нижнюю оценку взаимной информации между представлениями positive-пары:

$$
I(z_i; z_j) \geq \log N - \mathcal{L}_{\text{InfoNCE}}
$$

где $N$ — число negative-примеров. Следовательно, увеличение числа negatives повышает точность оценки взаимной информации, что теоретически обосновывает эффективность контрастивного обучения при больших размерах батча.

## 4.6. Оценка качества embeddings

Теоретически мы оцениваем наше решение вот так: silhouette, recall@K, KS, PR-AUC, ECE, Brier. Данный набор метрик обеспечивает комплексную характеристику качества embedding-пространства: геометрическую разделимость кластеров, точность процедуры retrieval, устойчивость к темпоральному сдвигу, дискриминативную способность и калибровку вероятностных оценок близости к anchors.

Протокол оценивания предусматривает фиксацию hold-out выборки (в частности, подмножества Elliptic++ с известными метками) и вычисление всех метрик на фиксированном разбиении train/validation/test с темпоральным разрезом во избежание утечки информации.

### 4.6.1. Silhouette score

Для объекта $i$, принадлежащего кластеру $C(i)$, silhouette-коэффициент определяется как:

$$
s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))} \in [-1, 1]
$$

где:
- $a(i) = \frac{1}{|C(i)|-1}\sum_{j \in C(i), j \neq i} d(i,j)$ — среднее внутрикластерное расстояние;
- $b(i) = \min_{C' \neq C(i)} \frac{1}{|C'|}\sum_{j \in C'} d(i,j)$ — среднее расстояние до ближайшего чужого кластера;
- $d(\cdot,\cdot)$ — евклидово расстояние в embedding-пространстве.

Интерпретация: $s(i) \approx 1$ — объект существенно ближе к собственному кластеру; $s(i) \approx 0$ — объект на границе кластеров; $s(i) < 0$ — объект, вероятно, отнесён к неверному кластеру. Агрегированная метрика — среднее $\bar{s} = \frac{1}{N}\sum_i s(i)$.

Теоретически мы оцениваем наше решение вот так: silhouette — вычисляется средний silhouette score на hold-out множестве с известными кластерами (Elliptic++); более высокое значение $\bar{s}$ свидетельствует о лучшей разделимости категорий в embedding-пространстве.

![silhouette_analysis](./files/4-6-1_silhouette_analysis.png)

*Распределение silhouette-коэффициентов по кластерам. Широкие столбцы с высокими значениями соответствуют хорошо отделённым кластерам. Красная вертикальная линия обозначает среднее значение $\bar{s}$ по выборке.*

### 4.6.2. Recall@K

Метрика Recall@K квантифицирует качество процедуры retrieval в embedding-пространстве.

**Процедура вычисления:**
1. Для каждого запроса $q$ из тестового множества определяется множество $R_K(q)$ — $K$ ближайших соседей в embedding-пространстве по косинусной близости.
2. Пусть $G(q)$ — множество ground-truth соседей $q$ (например, anchors, семантически связанных с $q$ по разметке Elliptic++ или по принадлежности к одному entity-кластеру).
3. Recall@K для запроса $q$: $\text{Recall@K}(q) = |R_K(q) \cap G(q)| / |G(q)|$.
4. Агрегированная метрика: $\text{Recall@K} = \frac{1}{|Q|}\sum_{q \in Q}\text{Recall@K}(q)$.

Теоретически мы оцениваем наше решение вот так: recall@K — измеряется на задаче anchor retrieval (для каждого кошелька из тестового множества оценивается доля истинно связанных anchors, попадающих в top-$K$ ближайших соседей); более высокое значение Recall@K указывает на более точное сохранение семантической близости.

Типичные значения $K \in \{10, 50, 100\}$; отчётность ведётся для всех трёх уровней.

### 4.6.3. Стабильность при темпоральном сдвиге (KS-тест)

Требование к embedding-пространству включает устойчивость во времени: при отсутствии изменений в поведении кошелька его представление не должно претерпевать статистически значимых сдвигов при инкрементальном обновлении графа.

**Метод.** Для двух временных срезов $t_1$ и $t_2$ формируются выборки проекций embeddings (покомпонентно или по распределению попарных расстояний). Применяется двухвыборочный критерий Колмогорова — Смирнова:

$$
D_{n,m} = \sup_x |F_{1,n}(x) - F_{2,m}(x)|
$$

где $F_{1,n}$, $F_{2,m}$ — эмпирические функции распределения. Нулевая гипотеза $H_0: F_1 = F_2$ отвергается при $p < 0.05$.

Теоретически мы оцениваем наше решение вот так: KS — для каждого временного среза вычисляется статистика $D_{n,m}$ и $p$-значение KS-теста между распределениями embeddings; отсутствие статистически значимых различий ($p \geq 0.05$) свидетельствует о темпоральной стабильности, наличие значимых различий является сигналом к необходимости retraining.

Визуализация embedding-пространства после обучения осуществляется посредством нелинейной проекции в $\mathbb{R}^2$ (t-SNE или UMAP) для качественного контроля кластерной структуры.

![embeddings in space](./files/4-7_embedding_tsne.png)

*Проекция 128-мерного embedding-пространства в $\mathbb{R}^2$ методом t-SNE. При корректном обучении anchors различных типов (OFAC, mixer, exchange) формируют компактные, взаимно отделённые кластеры; non-anchors распределены более дисперсно, но могут образовывать собственные структуры (DeFi-пулы, MEV-боты).*

### 4.6.4. Дискриминативные и калибровочные метрики (PR-AUC, ECE, Brier)

Для оценки способности embedding-близости предсказывать семантическую связь (например, принадлежность к одному entity-кластеру или близость к санкционному anchor) вводится бинарная задача: по расстоянию $d(q, a) = \|z_q - z_a\|_2$ предсказывается метка $y \in \{0,1\}$.

**PR-AUC.** Площадь под Precision-Recall кривой:

$$
\text{PR-AUC} = \int_0^1 \text{Precision}(R)\, dR
$$

где $\text{Precision}(R)$ — точность при уровне полноты $R$. Метрика устойчива к дисбалансу классов и приоритетна над ROC-AUC в условиях редкости positive-пар.

Теоретически мы оцениваем наше решение вот так: PR-AUC — вычисляется площадь под PR-кривой для задачи предсказания семантической связи по embedding-расстоянию; более высокое значение указывает на лучшую дискриминативную способность пространства.

**ECE (Expected Calibration Error).** Пусть предсказанная вероятность $\hat{p}_i = \sigma(-d_i)$ (или выход калиброванного классификатора на основе расстояния), разбиение на $M$ бинов $B_m$ по $\hat{p}$:

$$
\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \bigl|\text{acc}(B_m) - \text{conf}(B_m)\bigr|
$$

где $\text{acc}(B_m)$ — эмпирическая точность в бине, $\text{conf}(B_m)$ — средняя предсказанная уверенность.

**Brier score.**

$$
\text{Brier} = \frac{1}{N}\sum_{i=1}^{N} (\hat{p}_i - y_i)^2 \in [0,1]
$$

Минимальное значение соответствует идеальной калибровке и дискриминации.

Теоретически мы оцениваем наше решение вот так: ECE, Brier — вычисляются калибровочные ошибки предсказания связи по embedding-близости; более низкие значения свидетельствуют о корректной калибровке вероятностных оценок, что критично для downstream-пороговых решений.

Совокупность метрик PR-AUC, ECE и Brier дополняет геометрические метрики (silhouette, recall@K) и тест стабильности (KS), обеспечивая полную диагностику качества: дискриминация — калибровка — геометрия — устойчивость.

## 4.7. Выбор конфигурации: варианты и критерии

Пространство гиперпараметров контрастивного обучения многомерно; каждое проектное решение требует эмпирической валидации. Ниже специфицированы варьируемые факторы и протокол их сравнения.

### 4.7.1. Пространство поиска

| Фактор | Рассматриваемые варианты | Диапазон / примечания |
|--------|--------------------------|------------------------|
| Функция потерь | (a) чистый NT-Xent; (b) NT-Xent + anchor loss | Баланс $\lambda \in \{0, 0.1, 0.5, 1.0, 2.0\}$; при $\lambda=0$ сводится к (a) |
| Margin $m_0$ (anchor loss) | $m_0 \in \{0.5, 1.0, 2.0, 4.0\}$ | Взвешивается через $m_{\text{pull}}^{(L_1,L_2)} = m_0(1-J)$ |
| Размерность embedding | $d \in \{64, 128, 256\}$ | Компромисс выразительность / вычислительная стоимость CPU-inference |
| Температура $\tau$ | $\tau \in \{0.05, 0.1, 0.2\}$ | Дополнительно рассматривается $\tau=0.5$ как гладкий режим |
| Размер батча | $B \in \{256, 1024, 4096\}$ | Эффективный размер $2B$ после аугментации |
| Аугментации графа | (i) feature masking; (ii) edge dropping; (iii) node feature perturbation; (iv) комбинации (i)+(ii), (i)+(iii) | Уровень аугментации $p \in \{0.1, 0.2, 0.3\}$ |

### 4.7.2. Протокол сравнения

Для каждой конфигурации выполняются следующие тесты. Теоретически мы оцениваем наше решение вот так: silhouette, recall@K, KS, PR-AUC, ECE, Brier — каждая конфигурация ранжируется по совокупности метрик на валидационной выборке с темпоральным разрезом.

| Тест | Метрики | Критерий предпочтения |
|------|---------|------------------------|
| Геометрическая разделимость | silhouette ($\bar{s}$) | Максимизация $\bar{s}$ на hold-out кластерах Elliptic++ |
| Качество retrieval | Recall@K, $K \in \{10,50,100\}$ | Максимизация Recall@K на anchor retrieval |
| Дискриминация по расстоянию | PR-AUC | Максимизация PR-AUC для предсказания связи по $\|z_i-z_j\|_2$ |
| Калибровка | ECE, Brier | Минимизация ECE и Brier score |
| Темпоральная стабильность | KS-тест ($D_{n,m}$, $p$-значение) | Отсутствие значимых сдвигов распределений между временными срезами ($p \geq 0.05$) при сохранении дискриминации |
| Сходимость | Динамика $\mathcal{L}_{\text{NT-Xent}}$ на validation | Отсутствие расходимости; ранняя остановка по минимуму validation loss |

**Процедура выбора.** Применяется иерархический отбор:
1. Отсечение конфигураций с деградацией PR-AUC $>2$ п.п. относительно лучшего значения.
2. Среди оставшихся — минимизация ECE/Brier (калибровка).
3. При статистической неразличимости по PR-AUC/ECE (тест ДеЛонга для PR-AUC, bootstrap для ECE) предпочтение отдаётся конфигурации с более высоким silhouette и Recall@K.
4. Проверка KS-стабильности: конфигурации, демонстрирующие значимый дрейф ($p < 0.01$) при сохранении прочих метрик, штрафуются.
5. Финальный выбор учитывает вычислительные ограничения: при равенстве метрик предпочтение отдаётся меньшей размерности $d$ и меньшему батчу $B$.

**Ожидаемые эффекты (гипотезы для проверки):**
- Добавление anchor loss ($\lambda > 0$) повышает silhouette для anchor-кластеров и PR-AUC anchor retrieval ценой возможного снижения общей разделимости non-anchor кластеров; оптимальный $\lambda$ — предмет поиска.
- Увеличение $d$ с 64 до 128, как правило, повышает PR-AUC и Recall@K; переход к 256 даёт убывающую отдачу при росте стоимости хранения и CPU-поиска.
- Малые $\tau = 0.05$ усиливают чувствительность к hard negatives (рост Recall@K), но повышают ECE и риск нестабильности; $\tau = 0.2$ обеспечивает более гладкую калибровку.
- Большие батчи ($B=4096$) улучшают оценку взаимной информации (рост PR-AUC), но требуют пропорционального увеличения вычислительных ресурсов; $B=1024$ часто является парето-оптимальным.

## 4.8. Практические аспекты обучения

### 4.8.1. Размер батча

NT-Xent loss требует достаточного числа negative-примеров для состоятельной оценки знаменателя. Эмпирически рассматриваются $B \in \{256, 1024, 4096\}$. Увеличение $B$ монотонно улучшает PR-AUC и Recall@K до насыщения, однако вычислительная сложность растёт как $O(B^2 d)$ на шаг. В условиях Spillety обучение допускается на GPU, тогда как inference остаётся CPU-совместимым (см. компромисс по $d$).

### 4.8.2. Аугментации

Аугментация определяется как стохастическое преобразование графа, сохраняющее семантику узла при внесении вариативности для формирования positive-пар.

Рассматриваемые операторы:
- **Feature masking:** обнуление каждой компоненты признака узла с вероятностью $p$;
- **Edge dropping:** удаление каждого ребра с вероятностью $p$;
- **Node feature perturbation:** аддитивный гауссов шум $\mathcal{N}(0, \sigma^2)$ к признакам.

Уровень $p \in \{0.1, 0.2, 0.3\}$ и комбинация операторов являются предметом поиска по метрикам раздела 4.6. Чрезмерно агрессивные аугментации ($p > 0.3$, одновременное применение всех операторов) разрушают семантику и снижают PR-AUC; чрезмерно слабые ($p < 0.1$) не обеспечивают достаточной вариативности и снижают silhouette.

### 4.8.3. Температурный параметр $\tau$

Кандидаты $\tau \in \{0.05, 0.1, 0.2\}$ сравниваются по совокупности PR-AUC/ECE/Brier/silhouette/Recall@K. Малые значения $\tau$ повышают дискриминативную способность на hard negatives, но ухудшают калибровку (рост ECE); большие значения стабилизируют обучение ценой снижения Recall@K. Оптимальное значение $\tau$ определяется на валидационной выборке; типичный оптимум в литературе — $\tau = 0.07$–$0.1$.

## 4.9. Ограничения

1. **Зависимость от качества аугментаций.** Нарушение семантической инвариантности при аугментации порождает зашумлённые positive-пары, что деградирует все метрики, включая PR-AUC и silhouette. Контроль осуществляется через валидацию по ECE/Brier.

2. **Проблема ложных negatives.** В on-chain графе значительная доля формально negative-пар может быть скрыто связана (непубличные каналы, оффчейн-координация). Это вносит систематический шум, занижающий PR-AUC и Recall@K; mitigation — degree-corrected sampling и фильтрация hard negatives по entity-кластерам.

3. **Темпоральный дрейф.** Embeddings, оптимизированные на исторических срезах, подвержены деградации при появлении новых паттернов активности. Детекция дрейфа осуществляется KS-тестом (раздел 4.6.3); mitigation — периодический retraining с валидацией по PR-AUC/ECE на скользящем окне.

4. **Отсутствие абсолютной интерпретации расстояния.** Близость в embedding-пространстве является относительной мерой. Утверждение «близко к OFAC» не эквивалентно утверждению «является OFAC-сущностью» и требует downstream-процедур каузальной фильтрации и GBDT-скоринга для принятия решения. Калибровка вероятностных оценок (ECE, Brier) частично смягчает, но не устраняет данное ограничение.

---

**Резюме.** Контрастивное обучение обеспечивает оптимизацию отображения $f_\theta$ без потребности в полной ручной разметке, используя структурные связи графа как источник positive-сигналов и санкционные перечни как систему координат через anchor loss с взвешенным margin.

| Компонент | Функциональная роль | Наблюдаемый эффект |
|-----------|---------------------|---------------------|
| NT-Xent loss | Оптимизация на positive/negative парах | Embeddings, сохраняющие структурную близость; максимизация $I(z_i;z_j)$ |
| Anchor loss ($\lambda$, $m_0$) | Регуляризация относительно санкционных anchors | Компактификация anchor-области; параметр $\lambda$ балансирует геометрию |
| Weighted margin $m_0(1-J)$ | Учёт гетерогенности санкционных перечней | Корректное межкластерное расстояние между anchors различных типов |
| Оценка качества | Теоретически мы оцениваем наше решение вот так: silhouette, recall@K, KS, PR-AUC, ECE, Brier | Комплексная диагностика: геометрия, retrieval, стабильность, дискриминация, калибровка |
| Выбор конфигурации | Сравнение по сетке $\{d,\tau,B,m_0,\lambda,\text{aug}\}$ | Оптимум по PR-AUC/ECE/Brier при контроле silhouette/Recall@K/KS |

**Практические следствия:**
- Контрастивное обучение устраняет необходимость сплошной ручной разметки для оптимизации encoder'а.
- Anchor loss использует OFAC/EU/UN/OFSI как систему координат, а не как метки для классификации.
- Взвешенный margin $m_0(1-J)$ обеспечивает согласованность геометрии с эмпирическим перекрытием санкционных перечней.
- Теоретически мы оцениваем наше решение вот так: silhouette, recall@K, KS, PR-AUC, ECE, Brier — каждая конфигурация $\{ \text{NT-Xent vs NT-Xent+anchor},\; m_0,\; d \in \{64,128,256\},\; \tau \in \{0.05,0.1,0.2\},\; B \in \{256,1024,4096\},\; \text{augmentations} \}$ подлежит сравнению по совокупности данных метрик на hold-out выборке с темпоральным разрезом.
