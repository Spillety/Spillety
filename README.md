# Spillety

_Spill the tea about your transactions._

**Spillety** — студенческий Know Your Transaction движок, который решает две большие задачи: дорогой инференс на GPU и разметка данных. Наш подход был вдохновлён академической теорией и идеями из разделов математики и алгоритмики. 

| Показатель | Общепринятый подход | Подход Spillety | Идея |
|---|---|---|---|
| Разметка | Ручная экспертиза аналитиков и платные источники | Публичные санкционные списки как система координат | Уйти от зависимости от ручной разметки, опереться на регуляторный источник |
| Представления | Ручные признаки или GNN с дообучением на новых данных | Индуктивный графовый энкодер и контрастивное обучение | Масштабироваться на растущий граф без переобучения на каждом адресе |
| Поиск | Эвристики и перебор с последующей фильтрацией | Поиск близких anchors в пространстве представлений | Измерять близость, а не правила |
| Решение | Сквозные модели от признаков к решению | Разделение на retrieval и GBDT-решение | Оставить интерпретируемую часть решения отдельной |
| Порог | Порог по распределению скоров | Порог по стоимости ошибок с учётом нагрузки | Связать решение с бизнес-логикой, а не с формой распределения |
| Калибровка | Скор используется напрямую | Выбор метода калибровки на отложенной выборке | Привести скор к соответствию с наблюдаемой частотой |
| Эволюция | Переобучение по расписанию | Проверка обобщения на новых санкциях и детекция сдвига | Реагировать на изменения, а не на календарь |

_Столбец "Общепринятый подход" является примерным, так как топовые решения являются проприетарными._

### Подготовка данных

Notebooks читают elliptic датасет через единый `docs/notebooks/_elliptic_loader.py`. Чтобы скачать датасет, выполните команды ниже:

```bash
make data        # распакует archive.zip в папку data/elliptic_raw/ (или скачает из kaggle)
make notebooks   # pip install -r docs/notebooks/requirements-notebooks.txt
```
